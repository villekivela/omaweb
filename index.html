The package repository moved

This address no longer serves packages. If pacman sent you here, the Server line in your /etc/pacman.conf is the old one. 

[omaweb]
SigLevel = Required DatabaseRequired
Server = https://github.com/villekivela/omaweb/releases/download/repo-$arch

Then sudo rm /var/lib/pacman/sync/omaweb.db and sudo pacman -Syu. The signing key has not changed.

It moved because the engine package is larger than the 100 MB a git push accepts, and this repository was served from a branch. The decision record has the rest. Installing instructions are in the README.
