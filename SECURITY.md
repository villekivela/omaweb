# Security policy

Tanto is pre-alpha browser software. Do not use it for sensitive browsing yet.

## Report a vulnerability

Report suspected vulnerabilities through GitHub's
[private vulnerability reporting form](https://github.com/villekivela/tanto/security/advisories/new).
Do not open a public issue for an unpatched vulnerability.

Include the affected commit or version, steps to reproduce the problem, its
security impact, and any known workaround. Please allow time for a fix before
publishing details.
