Jobs API

Enqueue, inspect and cancel jobs. Every endpoint takes a bearer token.

Endpoint What it does
POST /v2/jobs Enqueue a job
GET /v2/jobs/:id Read a job's state
GET /v2/jobs/:id/trace Read its trace
POST /v2/jobs/:id/cancel Cancel a queued job

Enqueue a job

curl https://api.quillstack.test/v2/jobs \
  -H "Authorization: Bearer $QUILL_TOKEN" \
  -d queue=render-invoice -d payload.id=1042

Response

{
  "id": "job_8f2c1a",
  "state": "queued",
  "trace": "tr_51d0e9"
}
