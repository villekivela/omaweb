Tracing requests

Follow one job from the request that queued it to the worker that finished it, across every service it touched.

Turn tracing on

Pass a sampler when you create the client. Every job it enqueues carries a trace id.

import { Quill } from "@quillstack/sdk";

const quill = new Quill({
  token: process.env.QUILL_TOKEN,
  tracing: { sampler: "ratio", ratio: 0.25 },
});

// The trace id travels with the job.
await quill.jobs.enqueue("render-invoice", { id: 1042 });
Traces are kept for 14 days on every plan, and 90 days on Scale.

Read a trace

Open a job in the console, or fetch it with GET /v2/jobs/:id/trace. Spans are listed in the order they started.
