# Distribute only for Linux

Omaweb distributes end-user builds only for Linux, with Wayland as the primary display platform and
a native Arch package as the first package. macOS remains a supported development and CI platform,
but its application bundles are not signed, notarized, published, or qualified for end-user use.
This replaces ADR 0013's deferred macOS distribution direction; its sandbox rules and Linux package
decision still stand.
