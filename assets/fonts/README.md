# Material Symbols subset

`material-symbols-rounded-subset.ttf` is a self-hosted subset of Google's Material Symbols Rounded font. It contains these ligatures:

- `add`
- `arrow_back`
- `arrow_forward`
- `bookmark`
- `bookmark_border`
- `chevron_left`
- `chevron_right`
- `language`
- `refresh`
- `search`

The file came from the Google Fonts CSS API with `icon_names` sorted in the order above. The downloaded font URL reported version `v369`. Its SHA-256 digest is `928b60c0f79643fe6c0019fb40dd681b30b581ea1681c34cb218d3b7ee172d4c`.
