Omaweb/alpha/Arch x86_64 & aarch64

A keyboard-driven way to surf the web on Omarchy.

Omaweb uses your Omarchy theme’s colours, keeps your data on your machine, and lets you stay signed in to work and personal accounts in the same window.

01 / a tour, in your theme

It follows your theme.

Preview theme

Work and personal, side by side.

Spaces are separate identities inside one window. Each has its own cookies, logins, history, permissions and sessions, so you can be signed in to your work and personal accounts at the same time without a second browser or a private window.

Pinned tabs sit at the top of the sidebar, today’s tabs run underneath, and every new tab opens on the Start page.

Your keybindings.

Every binding lives in keybindings.json. Rebind any command, or give a key back to a site that wants it. Settings opens next to your tabs, in the same window.

Content blocking is built in.

EasyList and EasyPrivacy are on from the first run, along with cosmetic rules and scriptlets. Write your own rules in uBlock Origin’s syntax.

No account. No telemetry.

There’s nothing to sign up for, and no crash reports go anywhere. Each Space keeps its own history, and you can clear one without touching the others.

Sync is optional. It copies Spaces, tabs, keybindings and a few settings between your machines through a private repository you own. The Sync page lists what it copies.

Hide the sidebar and the page gets the whole window.

Ctrl+B brings it back. Mark a Pinned tab Keep active and it keeps running in the background, and Settings shows how much memory each one is using.

02 / getting it

Built for Arch.

Omaweb ships its own build of Qt WebEngine for Arch on x86_64 and Arch Linux ARM on aarch64. It installs alongside your system’s copy instead of replacing it, so nothing else on your machine changes, and engine security fixes arrive with Omaweb’s own updates.

From the Omaweb repository

Add these lines to /etc/pacman.conf. From then on Omaweb installs and updates along with the rest of your system. 

[omaweb]
SigLevel = Required DatabaseRequired
Server = https://github.com/villekivela/omaweb/releases/download/repo-$arch

Next, import the key the packages are signed with. You only do this once. Pacman installs nothing this key didn’t sign, and a keyserver will hand out any key that claims the right name, so the third command trusts only the fingerprint published on this page. The key downloads over HTTPS because many networks block the port keyservers use.

Packages are built for x86_64 and aarch64, and pacman picks the right one for your machine. If you’d rather not add a repository, the README covers the other ways to install. 

$curl -fsSLO https://raw.githubusercontent.com/villekivela/omaweb/main/security/repo-signing-key.asc
$sudo pacman-key --add repo-signing-key.asc
$sudo pacman-key --lsign-key FDA535B2185755EA718BEA585DBF15FE484EFA64
$sudo pacman -Syu omaweb

Keeping it current

Omaweb tells you when a new version is out. A notice appears at the bottom of the sidebar with the version and how to get it, and selecting it opens the release notes. Omaweb never installs anything by itself. With the repository added, it updates with the rest of your system. Without it, download the new package and install it the same way as the first one. You can turn the check off in Settings, under About. 

$sudo pacman -Syu
