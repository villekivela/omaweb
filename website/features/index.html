Features

What is in the browser.

Everything here works today, on the release you can download, unless the item says otherwise. The landing page says why the browser is the way it is; this is what is actually in it.

  • Spaces

    Separate browsing identities in one window. Each Space keeps its own cookies, logins, history, permissions, sessions and tabs.

  • Split

    Two tabs of a Space side by side where one webpage would be, listed as one sidebar row. Lands in the next release.

  • The Omnibar

    One centred overlay opens addresses, searches the web, selects tabs and Spaces, and invokes browser commands. Every browser action is reachable from it.

  • Keyboard navigation

    Configurable bindings, link hints, and a shortcut sheet generated from the keymap you are actually running rather than from a written list of it.

  • Tabs that come back

    Pinned tabs, Private windows, site-requested Auxiliary windows, and recently closed tabs. Mark a Pinned tab Keep active and its page keeps running in the background.

  • Content blocking

    EasyList, EasyPrivacy, cosmetic rules, Scriptlets and Substitute resources. Your own rules use uBlock Origin’s syntax, and Settings reports what each list contributed and what it skipped.

  • Site information

    Connection state, certificate errors, permissions, stored data and what Content blocking did, for the page in front of you.

  • Downloads that ask first

    A high-risk download is confirmed before it starts, loses its execute permission, and is never opened for you.

  • Sync, if you want it

    Optional, and local-only until you connect it. It copies Spaces, tabs, keybindings and a few settings between your machines through a private repository you own. What it copies.

  • Themes without a restart

    Omaweb follows the desktop theme and can import terminal and Omarchy themes while it is running.

What Omaweb does not do.

These are scope decisions rather than unfinished work, so none of them is on the way.

No bookmarks, password management, third-party WebExtensions, Account system, installed web applications, Reader mode, translation, browser-data import, View source, spellchecking or DRM.

No telemetry, advertising identifier, browser account, hosted Omaweb service, push service or automatic crash upload. The network request ledger lists every automatic request the browser makes.
