Browser for Omarchy

The browser should be
part of your desktop,
not a guest on it.

A keyboard-driven browser for Omarchy. It wears the desktop's theme and keeps its data on your machine.

Install Read the source Build from source Alpha Expect bugs, and desktop integration that is not finished. The README says what works today.

01 / the window itself

The window, in every theme.

Omaweb reads its colours from whichever Omarchy theme you are running. Pick one to see the whole browser in it.

Preview theme

02 / yours to configure

Nothing you cannot change.

omarchy theme set picks the theme. Everything else is a file on your machine.

Keys you own

Every browser binding lives in keybindings.json. Rebind a command there, or hand a key back to the page when a site wants it.

Local by default

No browser account, no telemetry, no crash reports sent anywhere. Your browsing data stays on your disk.

03 / browsing identities

Work and personal stay in the same window.

A Space holds the browsing data of one part of your life, and nothing else's.

Keep accounts apart

Each Space has its own cookies, logins, history, permissions and session. Two accounts on the same site stay logged in at once, with no second browser and no private window.

Pick up where you left off

Pinned tabs come back when a Space resumes. Mark one as Keep active and it keeps running in the background. Settings lists every tab kept this way, with the memory each one is using.

04 / getting it

Install it on Arch.

Omaweb links against the Qt that Arch ships. When Arch patches the engine, you get the fix with your next system update, not with a new Omaweb release.

From a release

Every release from v0.2.0 on includes a built package. Download it and install it with pacman. Packages are x86_64 only. On aarch64, build from the repository. 

$sudo pacman -U omaweb-git-*.pkg.tar.zst

From the repository

Clone the repository and build the package yourself. This gives the same package on either architecture. Installing does not make Omaweb your default browser. It is alpha, so that stays a choice you make in Settings. 

$git clone https://github.com/villekivela/omaweb.git
$cd omaweb/packaging && makepkg -si
