# Icons

`omaweb.svg` is the wordmark as the editor that made it saved it, drawn black. It is the source the
inline wordmark in the page was copied from, not a file the page loads: the page's copies, in the
header, the footer and the poster, carry the same two paths and take their colours from the page's
stylesheet. A change to the drawing is a change here first, then to each copy.

The favicon lives at `website/favicon.svg`: the application icon in black and white, edited by hand.
It is a file rather than a `data:` URL because Omaweb's engine shows no icon for one of those.
