# Icons

`omaweb.svg` is the wordmark, drawn black by the editor that made it. It is the source the per-theme
copies are generated from, not a file the page loads.

Everything else here is generated by `scripts/build_website_themes.py` and should not be edited:

- `wordmark-<theme>.svg`, the wordmark in that theme's foreground.
- `favicon-<theme>.svg`, the application icon from `assets/icons/omaweb.svg` in that theme's ground
  and foreground.

The default theme's favicon is also written to `website/favicon.svg`, which is where a browser asks
for it. `index.html` names the theme each element starts on and carries the path the switcher
rewrites, in `data-themed`.
